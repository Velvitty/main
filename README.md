## 사용 방법

현재는 문서만 확인할 수 있습니다. 저장소를 내려받아 확인하려면 GitHub의 **Code → Download ZIP**을 사용하거나, Git이 설치된 환경에서 다음 명령을 실행하세요.

```sh
git clone https://github.com/Velvitty/main.git
cd main
```

아직 설치하거나 실행할 프로그램 명령은 없습니다.

## 기술 구성 현황

현재 등록된 파일은 Markdown 문서 1개입니다. 따라서 프로그램의 상세 사양은 다음과 같이 구분됩니다.

| 구성 영역 | 현재 확인되는 내용 |
| --- | --- |
| 문서 형식 | GitHub에서 표시하는 Markdown (`README.md`) |
| 실행 진입점 | 없음: `index.html`, 실행 스크립트, 바이너리 미등록 |
| 언어·런타임·의존성 | 프로그램 소스와 의존성 목록 미등록 |
| UI·알고리즘·데이터 모델 | 구현이 없어 사양을 확인할 수 없음 |
| 데이터 저장·외부 API | 관련 코드 또는 설정 없음 |
| 빌드·테스트·CI | 관련 구성 파일 없음 |
| 사용자 도메인 | `CNAME` 없음. 이 저장소에서 확인되는 HTTPS 앱 주소 없음 |

이 저장소의 `main`이라는 이름만으로 다른 저장소의 통합 앱, 배포 진입점 또는 계정 소개 페이지라고 해석하지 않습니다. 현재 문서는 등록된 파일과 확인 가능한 상태만 설명합니다.
