## 사용 방법

현재는 문서만 확인할 수 있습니다. 저장소를 내려받아 확인하려면 GitHub의 **Code → Download ZIP**을 사용하거나, Git이 설치된 환경에서 다음 명령을 실행하세요.

```sh
git clone https://github.com/Velvitty/main.git
cd main
```
